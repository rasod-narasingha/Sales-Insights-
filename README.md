📊 Sales Insight Dashboard

A powerful and interactive Sales Insight Dashboard built using Power BI and MySQL to analyze sales performance and support data-driven decision making.

🚀 Project Overview

This project provides a comprehensive view of sales data through dynamic dashboards.
It helps businesses to:

Track total revenue and profit

Analyze monthly & yearly sales trends

Identify top-performing products and regions

Monitor customer behavior

Improve strategic planning

🛠 Technologies Used

🟡 Power BI – Data visualization & dashboard creation

🐬 MySQL – Database management & data storage

📂 SQL Queries – Data extraction & transformation

📈 Features

✔ Interactive visual dashboards
✔ Real-time data insights
✔ Filter by date, region & product
✔ Performance comparison reports
✔ Easy-to-understand charts & KPIs

🗂 Dataset

Sales data stored in MySQL database
Includes:

Customer details

Product information

Order history

Revenue & profit metrics

⚙ How It Works

Data stored in MySQL database

Power BI connects to MySQL

Data cleaned & transformed

Visual dashboards created

Insights generated for business decisions
